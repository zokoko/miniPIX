训练原理与边界
透明展示模型实际在学什么
① 全量素材 + 组合增强
每个 Epoch 覆盖全部原始像素图，并加入透明前景与随机多物体图像；模型在像素序列上执行 teacher forcing
↓
② 前向传播
164D 文本语义 + 模式条件 + 绝对 XY 位置 → token embedding + 因果自注意力 + FFN → 128 类 next-patch logits
↓
③ 损失函数
训练损失 = patch token 的 next-token cross-entropy；透明前景样本使用前景/空白 token 加权，避免模型只学会全透明输出
↓
④ 反向传播 + Adam
通过注意力、FFN、文本/位置投影和 token embedding 的链式反向传播 → Adam 更新实际参数
当前主模型是可训练的轻量级自回归像素 Transformer（单层、单头、32-token 上下文、16 维隐藏状态），自回归预测 625 个 4×4 patch token，再解码到原生 100×100 像素。它不是大型扩散模型；数据量和模型容量有限，早期训练输出可能有噪声，通常需要多轮训练。内置目标图是程序绘制的像素素材，不是大型真实图文语料。
